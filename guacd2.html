Apache Guacamole 完整部署手册

面向多区域节点 (US/EU) 的高可用分布式混合架构

一、 架构概览与优势

本方案采用 主控节点（整合版镜像） + 远端节点（纯净版镜像） 的组合策略。不仅解决了跨国直连高延迟、易丢包的痛点，更统一了全球机器的权限入口。

  • 极致性能： 跨国网络仅传输极限压缩后的 HTML5 画布，原生沉重的 RDP/SSH 流量在远端机房内部实现 0 延迟闭环。
  • 统一安全： 所有被控机无需对外开放 3389/22 端口，凭证由数据库统一保管，团队成员通过 Web 账号打卡直连，阻断全网暴力破解。
  • 无痛免客户端： PC、手机、平板无需安装任何软件，浏览器即开即用。

二、 Docker 核心部署命令

1. 主控中心 (以 LA 节点为例) - 必须部署

使用带有 Web 界面和数据库的 整合版镜像。负责提供登录面板，并可以直接接管 LA 本地的所有服务器，无需再做转发。

docker run -d \
  --name guacamole-master \
  --restart always \
  -p 8080:8080 \
  -v /opt/guacamole:/config \
  oznu/guacamole

2. 远端被控节点 (以 FRA/DE 为例) - 二选一

方案 A：纯净干活版（最推荐，省资源）

仅运行不到 20MB 的底层转码核心，无 Web 面板，专门向 LA 主控提供代理服务。

docker run -d \
  --name guacd-edge \
  --restart always \
  -p 4822:4822 \
  guacamole/guacd

方案 B：全能双开版（如果你想保留 FRA 自己的独立面板）

使用整合版镜像，但同时暴露出 4822 端口。这样 FRA 既有自己的 8080 登录页，又能充当 LA 主控的代理节点。

docker run -d \
  --name guacamole-master-node \
  --restart always \
  -p 8080:8080 \
  -p 4822:4822 # 核心：对外暴露底层转码端口供 LA 调用
  -v /opt/guacamole:/config \
  oznu/guacamole
节点安全必做 (防火墙规则)： 无论是方案 A 还是 B，远端节点的 4822 端口严禁直接向全网开放。请使用 Tailscale 内网 IP，或配置 UFW 防火墙：
ufw allow from <LA主控的公网IP> to any port 4822

三、 反向代理与 HTTPS 配置 (仅在主控 LA 节点执行)

必须启用 WebSocket (Upgrade)，否则画面将断开或极其卡顿。

图形化面板: Nginx Proxy Manager (NPM)

  • Details: 填入您的域名，Forward IP 填 172.17.0.1 或主机内网IP，Port 填 8080。
  • 核心操作: 必须勾选 Websockets Support。
  • SSL: 申请证书并勾选 Force SSL。

代码配置: 原生 Nginx

location / {
    proxy_pass http://127.0.0.1:8080/;
    proxy_buffering off;
    proxy_http_version 1.1;
    # 必须携带以下两行支持 WebSocket
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header Host $http_host;
}

五、 团队多用户协作与权限隔离 (RBAC)

系统底层账号结合 Guacamole 的权限映射，可以完美实现开发资源的多租户隔离分配。

  1. 系统层隔离创建： 在目标服务器（Linux 或 Windows Server）底层创建多个独立子账号（如 dev_01, dev_02）。
  2. 创建一对一连接： 在 Web 面板建立对应的多个连接，网络参数相同，仅系统账号密码不同。
  3. 按角色分配： 创建 Web 用户时，仅勾选赋予该成员对应的桌面权限。
管理增效提示： 独立的开发工作空间不仅避免了环境冲突，也能让项目组的管理更加结果导向——由于环境与代码是物理隔离的，无需过度关注基础考勤打卡，而是将评估重心完全聚焦于各个环境实际产出的核心 KPI 结果。离职或调岗时，只需在后台一键停用 Web 账号即可完成权限回收。

六、 移动端 (手机/平板) 专属高阶操作

Guacamole 对移动端无键盘环境做了深度适配，所有隐藏功能均可通过手势呼出：

  • 呼出侧边栏： 在屏幕最左侧边缘，手指向右滑动，即可唤出黑色控制面板。
  • 剪贴板同步： 侧边栏内的文本框即为双向剪贴板。长按粘贴内容进去，即可发送到远程机器；远程复制的内容，也会出现在这里供手机复制。
  • 虚拟鼠标 (解决误触)： 在侧边栏中找到“鼠标模拟 (Mouse Emulation)”，将其切换为 触摸板 (Touchpad)。此时整个手机屏幕将变成笔记本的触控板，滑动控制光标，单指轻敲为左键，双指轻敲为右键。
  • 输入法呼出： 侧边栏顶部点击“文本输入 (Text Input)”，即可唤出手机自带键盘，敲击代码或命令毫无压力。
