Typecho Docker 全能部署与维护手册

⚠️ 核心避坑点： 原教程中挂载 config.inc.php 文件会导致 Docker 误将其识别为文件夹，产生 "Not a directory" 报错。本教程已通过全目录挂载修复此问题。

一、 快速部署 (Docker Compose)

基于 /root/data/docker/typecho 路径的规范化部署。

1. 环境清理与目录准备

在开始之前，确保清理掉之前失败的容器和残留的“错误文件夹”。

# 停止并删除旧容器
docker rm -f typecho typecho-db

# 准备目录
mkdir -p /root/data/docker/typecho/{typecho,db}
cd /root/data/docker/typecho

# 【重要】检查并删除之前误创建的 config.inc.php 文件夹
rm -rf typecho/config.inc.php

# 赋予权限（防止安装程序无法写入）
chmod -R 777 /root/data/docker/typecho

2. 编写 docker-compose.yml

services:
  typecho:
    image: joyqi/typecho:nightly-php8.2-apache
    container_name: typecho
    restart: always
    ports:
      - "8383:80"
    environment:
      - TZ=Asia/Shanghai
    volumes:
      - ./typecho:/app  # 挂载整个程序目录，包含代码和配置
    depends_on:
      - db

  db:
    image: mariadb:10.6
    container_name: typecho-db
    restart: always
    environment:
      - MYSQL_ROOT_PASSWORD=your_root_password
      - MYSQL_DATABASE=typecho
      - MYSQL_USER=typecho
      - MYSQL_PASSWORD=your_typecho_password
      - TZ=Asia/Shanghai
    volumes:
      - ./db:/var/lib/mysql

3. 启动命令

docker compose up -d

注意：如果启动后 ./typecho 目录依然为空，请执行一次手动拷贝（仅需一次）：

docker cp typecho:/app/. ./typecho/ && chmod -R 777 ./typecho

4. Web 界面安装配置

打开浏览器，访问：http://你的服务器IP:8383

在数据库配置页面，务必按以下信息填写：

  • 数据库类型： MySQL 或 Pdo_Mysql
  • 数据库地址： db (不要写 localhost)
  • 数据库端口： 3306
  • 数据库用户名： typecho
  • 数据库密码： your_typecho_password (你在 YAML 中设置的密码)
  • 数据库名： typecho
🎉 部署完成！
安装完成后，所有的主题（themes）、插件（plugins）和上传的图片都会保存在宿主机的 /root/data/docker/typecho/typecho 目录下。备份时只需打包此文件夹即可。

二、 反向代理配置 (HTTPS)

推荐使用 Nginx Proxy Manager (NPM) 或原生 Nginx。

1. 使用 Nginx Proxy Manager 配置

项目配置内容
Domain Names你的域名 (如: blog.example.com)
Schemehttp
Forward Host Name / IP服务器公网IP 或 Docker网桥IP (172.17.0.1)
Forward Port8383
Block Common Exploits开启 (ON)
Websockets Support开启 (ON)

2. 原生 Nginx 配置示例

server {
    listen 80;
    server_name blog.yourdomain.com;
    
    location / {
        proxy_pass http://127.0.0.1:8383;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

三、 日常维护命令

所有命令需在 /root/data/docker/typecho 目录下执行。

1. 基本操作

  • 查看日志 docker compose logs -f typecho (排查报错神器)
  • 重启服务 docker compose restart
  • 进入容器 docker exec -it typecho /bin/bash

2. 备份与迁移 (最重要)

Typecho 迁移非常简单，只需备份整个文件夹：

# 压缩备份所有数据
tar -czvf typecho_backup_$(date +%F).tar.gz /root/data/docker/typecho

3. 升级 Typecho 镜像

docker compose pull     # 拉取新镜像
docker compose up -d    # 重新创建容器
docker image prune -f   # 清理旧镜像

四、 进阶配置 Tips 及常见问题排查

1. 常见问题排查

  • 访问 500 错误： 通常是 chmod -R 777 typecho 没执行成功，权限不足导致。
  • 无法连接数据库： 检查数据库地址是否填写的 db，以及密码是否与 YAML 中一致。
  • 目录没内容： 参考第一步的 docker cp 命令将容器内初始文件拷贝出来。

2. 解除上传附件大小限制

如果无法上传大文件，需在 ./typecho 目录下创建或修改 .user.ini：

upload_max_filesize = 64M
post_max_size = 64M

3. 强制 HTTPS 跳转

在 Typecho 后台设置“站点地址”为 https://... 之后，如果样式乱了，在 config.inc.php 开头添加：

define('__TYPECHO_SECURE__', true);
