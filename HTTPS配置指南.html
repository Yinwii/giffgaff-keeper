局域网 HTTPS 部署与权限激活指南

解决局域网环境下浏览器禁用“剪贴板 API”及“粘贴限制”报错的最终方案

为什么需要 HTTPS？

现代浏览器出于安全考虑，仅在 Secure Context (安全上下文) 环境下允许网页使用高性能剪贴板接口。 通过 IP 访问（如 192.168.x.x）被视为不安全，导致系统回退到低效复制模式，进而引发 Excel 粘贴限制报错。配置 HTTPS 后，所有权限将自动解锁。

标准目录结构

请确保以下文件位于同一个文件夹内（文件夹名称任意）：

1

生成自签名证书 (server.pem)

在系统终端（CMD 或 PowerShell）中运行以下指令。该脚本使用 Python 自带库生成一个有效期 1 年的本地证书。

python -c "from cryptography import x509; from cryptography.hazmat.primitives import hashes; from cryptography.hazmat.primitives.asymmetric import rsa; from cryptography.hazmat.primitives import serialization; import datetime; key = rsa.generate_private_key(public_exponent=65537, key_size=2048); subject = issuer = x509.Name([]); cert = x509.CertificateBuilder().subject_name(subject).issuer_name(issuer).public_key(key.public_key()).serial_number(x509.random_serial_number()).not_valid_before(datetime.datetime.utcnow()).not_valid_after(datetime.datetime.utcnow() + datetime.timedelta(days=365)).sign(key, hashes.SHA256()); print(key.private_bytes(serialization.Encoding.PEM, serialization.PrivateFormat.TraditionalOpenSSL, serialization.NoEncryption()).decode() + cert.public_bytes(serialization.Encoding.PEM).decode())" > server.pem
如果提示缺少库，请先运行：pip install cryptography
2

编写 HTTPS 启动脚本 (run_https.py)

创建一个名为 run_https.py 的文件，并将以下代码粘贴进去。将其放在 HTML 文件所在的目录。

import http.server
import ssl
import socket

# 配置
PORT = 44433 
CERT_FILE = 'server.pem'

def get_ip():
    s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    try:
        s.connect(('8.8.8.8', 80))
        ip = s.getsockname()[0]
    except:
        ip = '127.0.0.1'
    finally:
        s.close()
    return ip

class SimpleHandler(http.server.SimpleHTTPRequestHandler):
    def end_headers(self):
        self.send_header('Cache-Control', 'no-store, no-cache, must-revalidate')
        super().end_headers()

server_address = ('0.0.0.0', PORT)
httpd = http.server.HTTPServer(server_address, SimpleHandler)

# 配置 SSL 证书
context = ssl.SSLContext(ssl.PROTOCOL_TLS_SERVER)
context.load_cert_chain(CERT_FILE)
httpd.socket = context.wrap_socket(httpd.socket, server_side=True)

lan_ip = get_ip()
print(f"\n" + "="*40)
print(f"🚀 FPY HTTPS 服务已就绪!")
print(f"🔗 局域网访问: https://{lan_ip}:{PORT}")
print(f"⚠️  提示: 必须以 https:// 开头访问。")
print("="*40 + "\n")

httpd.serve_forever()
3

终端启动并信任证书

  1. 在命令行运行：python run_https.py
  2. 在浏览器访问控制台显示的 https://[IP]:44433。
  3. 由于是自签名证书，浏览器会拦截提示“不安全”。
  4. 点击屏幕上的 “高级” -> “继续前往 [IP] (不安全)”。
  5. 进入系统后，再次测试“分析明细表”的复制功能，粘贴到 Excel 将不再报错。
