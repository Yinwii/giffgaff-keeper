Ubuntu 24.04 XanMod (BBRv3) 优化方案

服务器环境： OVH SAS (Oregon, US)
硬件配置： Intel Haswell CPU (4 Cores), 8GB RAM
核心痛点： 跨境丢包导致到中国内地上传速度极低（仅 0.36 Mbps）

第一步：安装 XanMod x64v3 内核

针对 OVH 机房 IP 屏蔽 dl.xanmod.org (403错误) 的问题，采用 Ubuntu 官方密钥服务器绕过方案。

# 1. 导入 GPG 密钥 (从 Ubuntu 官方密钥服务器拉取)
sudo mkdir -p /etc/apt/keyrings
sudo gpg --no-default-keyring --keyring /etc/apt/keyrings/xanmod-archive-keyring.gpg --keyserver hkp://keyserver.ubuntu.com:80 --recv-keys 86F7D09EE734E623

# 2. 添加 XanMod 官方软件源
echo 'deb [signed-by=/etc/apt/keyrings/xanmod-archive-keyring.gpg] http://deb.xanmod.org releases main' | sudo tee /etc/apt/sources.list.d/xanmod-release.list

# 3. 安装针对 Haswell 优化的 x64v3 内核
sudo apt update && sudo apt install linux-xanmod-x64v3 -y

第三步：清理冗余内核与残留

    
保持系统纯净，仅保留 XanMod 内核和官方保底内核。

    
# 1. 卸载过渡内核 (如 Liquorix)
sudo apt purge linux-image-liquorix-amd64 linux-headers-liquorix-amd64 -y

# 2. 彻底清除旧内核残留配置文件 (状态为 deinstall 的包)
sudo dpkg --purge linux-image-6.8.0-86-generic

# 3. 自动清理无用依赖
sudo apt autoremove -y && sudo update-grub
