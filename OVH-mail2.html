OVH 自建邮局终极实操指南

✅ 环境就绪： Ubuntu 24.04 | XanMod v3 | BBR3 已激活 | 8GB RAM | 25 端口已放行

1 域名基建 (DNS & PTR)

必须关闭 Cloudflare 小黄云 (灰色云朵 DNS Only)，否则 SSL 握手和发信校验将失败。

PTR 必做： 登录 OVH 面板，为 IPv4 和 IPv6 均设置 Reverse DNS 为 mail.yourdomain.com。
类型主机名记录值说明
Amail15.204.x.x服务器 IPv4 地址
AAAAmail2604:2dc0...服务器 IPv6 地址
MX@mail.yourdomain.com指向邮件服务器，优先级 10
TXT@v=spf1 mx ~allSPF 授权：允许此 IP 发信
TXT_dmarcv=DMARC1; p=quarantine; adkim=r; aspf=rDMARC 策略：防止被冒用

2 邮局部署 (Poste.io)

使用单镜像全能方案。关键点：必须用 host 网络模式（端口直接监听宿主机，无需 -p 映射；bridge + -p 写法会让邮件日志里的客户端 IP 全部变成 docker 网关地址，破坏 rspamd 发件人信誉判断与 fail2ban 封禁逻辑）。默认禁用杀毒参数，启动后内存占用仅约 350MB，重启后 ClamAV 也不会复活（run 脚本检测到 DISABLE_CLAMAV 会自动停用）。
mkdir -p /home/docker/mail && docker run -d --name mailserver \
  --network host --restart always \
  -e HTTPS=ON \
  -e DISABLE_CLAMAV=TRUE \
  -e TZ=Europe/Prague \
  -v /home/docker/mail:/data \
  analogic/poste.io

3 核心管理命令详解

1. 内存监测：mailmem 基础命令

功能：静态查看容器占用的物理内存百分比。确认 ClamAV 关闭后应在 4~5% 左右（约 350MB）；若显示 20%（约 1.5GB），说明 ClamAV 又跑起来了。

docker stats mailserver --no-stream

2. 杀毒进程审计

功能：确认容器内 clamd 进程是否运行。如果有输出，说明它正在消耗 1GB 内存。

docker exec mailserver ps aux | grep clamd

3. 精准控制杀毒 (仅临时手段)

功能：使用 s6 管理器实时关闭/开启 clamd。注意：此方法只对当前容器生命周期有效，容器或宿主机重启后 clamd 会自动复活。永久禁用请使用第 2 节部署命令中的 -e DISABLE_CLAMAV=TRUE 参数（部署时带上即可，无需再手动停）。

docker exec mailserver s6-svc -d /var/run/s6/services/clamd
docker exec mailserver s6-svc -u /var/run/s6/services/clamd

4 长期管理别名 (一键配置)

将上述命令封装为快捷键。配置后输入 mailmem 查内存、clamoff 临时释放内存。提醒：clamoff 属临时手段，容器重启后需重新执行；永久方案是部署命令里的 DISABLE_CLAMAV 参数。

cat <> ~/.bashrc
# Poste.io 内存优化快捷键
alias mailmem='docker stats mailserver --no-stream'
alias clamoff='docker exec mailserver s6-svc -d /var/run/s6/services/clamd && echo "✅ clamd 已关闭，内存正在释放..."'
alias clamon='docker exec mailserver s6-svc -u /var/run/s6/services/clamd && echo "🚀 clamd 已启动"'
EOF
source ~/.bashrc

5 移动端与 PC 连接指南

无论使用 iPhone、Android 还是 Outlook，请统一手动配置以下 SSL 参数：
协议服务器地址端口加密方式
IMAP (收)mail.yourdomain.com993SSL/TLS
SMTP (发)mail.yourdomain.com465SSL/TLS
登录凭证： 用户名必须是完整邮箱地址。如果 SSL 连接失败，请检查防火墙是否允许 993/465 端口。

5.1 新版 Outlook（免费版）添加 w@lilary.com 实操（2026-11-19 验证通过）

新版 Outlook（Microsoft.OutlookForWindows）不支持 POP，自建邮箱只能走 IMAP。 添加路径：设置（齿轮）→ 添加账户 → 输入 w@lilary.com → 探测失败时选「高级选项 / 手动设置 → IMAP」，按下表填写：
字段填写值
电子邮件w@lilary.com
用户名w@lilary.com（完整地址）
密码Poste.io 后台为该邮箱设置的邮箱密码（不是任何微软账号密码）
收件服务器 (IMAP)mail.lilary.com
收件端口 / 加密993 + SSL/TLS
发件服务器 (SMTP)mail.lilary.com
发件端口 / 加密465 + SSL/TLS（若不被接受改 587 + STARTTLS，两端口均已实测放通）
发件需要身份验证勾选，凭据同收件
三个注意点：
1. Cloud Sync： 新版 Outlook 会把 IMAP 邮件同步到微软云做索引，BW25（152.53.86.5）上仍是原件；介意隐私的用 classic Outlook（需授权）或 Thunderbird。
2. 端口检测： 添加前可先在 PC 上 Test-NetConnection mail.lilary.com -Port 993 验证连通，已实测 25/143/465/587/993 全部开放。
3. 界面变英文： 设置 → General → Language and time → Display language 选「中文(简体)」，应用会自动下载语言包并重启。

6 进阶测试与维护

  1. 跑分测试： 前往 Mail-Tester.com，目标 10/10 满分。
  2. DKIM 配置： 在 Poste.io 后台生成密钥后，在 DNS 添加 s1._domainkey 的 TXT 记录。
  3. 防火墙放行： sudo ufw allow 993/tcp 465/tcp 80/tcp
