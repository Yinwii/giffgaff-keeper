OVH 自建邮局终极实操指南

✅ 环境就绪： Ubuntu 24.04 | XanMod v3 | BBR3 已激活 | 8GB RAM | 25 端口已放行

1 域名基建 (DNS & PTR)

必须关闭 Cloudflare 小黄云 (灰色云朵 DNS Only)，否则 SSL 握手和发信校验将失败。

PTR 必做： 登录 OVH 面板，为 IPv4 和 IPv6 均设置 Reverse DNS 为 mail.yourdomain.com。
类型主机名记录值说明
Amail15.204.x.x服务器 IPv4 地址
AAAAmail2604:2dc0...服务器 IPv6 地址
MX@mail.yourdomain.com指向邮件服务器，优先级 10
TXT@v=spf1 mx ~allSPF 授权：允许此 IP 发信
TXT_dmarcv=DMARC1; p=quarantine; adkim=r; aspf=rDMARC 策略：防止被冒用

2 邮局部署 (Poste.io)

使用单镜像全能方案。默认加入禁用杀毒参数，启动后内存占用仅约 700MB。
mkdir -p /home/docker/mail && docker run -d --name mailserver \
  -e HTTPS=ON \
  -e DISABLE_CLAMAV=TRUE \
  -p 25:25 -p 465:465 -p 587:587 -p 993:993 -p 8080:8080 \
  -v /home/docker/mail:/data \
  analogic/poste.io

3 核心管理命令详解

1. 内存监测：mailmem 基础命令

功能：静态查看容器占用的物理内存百分比。确认 ClamAV 关闭后应在 20% 左右。

docker stats mailserver --no-stream

2. 杀毒进程审计

功能：确认容器内 clamd 进程是否运行。如果有输出，说明它正在消耗 1GB 内存。

docker exec mailserver ps aux | grep clamd

3. 精准控制杀毒 (基于运行时)

功能：使用 s6 管理器直接关闭或开启 clamd 进程，实时释放内存。

docker exec mailserver s6-svc -d /var/run/s6/services/clamd
docker exec mailserver s6-svc -u /var/run/s6/services/clamd

4 长期管理别名 (一键配置)

将上述复杂命令封装为简单快捷键。配置后，输入 clamoff 即可释放 1GB 内存。

cat <> ~/.bashrc
# Poste.io 内存优化快捷键
alias mailmem='docker stats mailserver --no-stream'
alias clamoff='docker exec mailserver s6-svc -d /var/run/s6/services/clamd && echo "✅ clamd 已关闭，内存正在释放..."'
alias clamon='docker exec mailserver s6-svc -u /var/run/s6/services/clamd && echo "🚀 clamd 已启动"'
EOF
source ~/.bashrc

5 移动端与 PC 连接指南

无论使用 iPhone、Android 还是 Outlook，请统一手动配置以下 SSL 参数：
协议服务器地址端口加密方式
IMAP (收)mail.yourdomain.com993SSL/TLS
SMTP (发)mail.yourdomain.com465SSL/TLS
登录凭证： 用户名必须是完整邮箱地址。如果 SSL 连接失败，请检查防火墙是否允许 993/465 端口。

6 进阶测试与维护

  1. 跑分测试： 前往 Mail-Tester.com，目标 10/10 满分。
  2. DKIM 配置： 在 Poste.io 后台生成密钥后，在 DNS 添加 s1._domainkey 的 TXT 记录。
  3. 防火墙放行： sudo ufw allow 993/tcp 465/tcp 80/tcp
