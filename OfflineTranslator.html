🚀 局域网专属 AI 翻译服务器
(全平台离线部署完整教程)

⚠️ 环境准备： 请确保电脑已安装 Python 3.11 或 3.12。Windows 用户在安装时务必勾选 Add Python to PATH。

第一步：建立项目文件夹与模型

1. 新建一个文件夹，命名为 OfflineTranslator，进入该文件夹。

2. 在里面再新建一个名为 models 的文件夹。

3. 将你下载好的 AI 模型文件（如 .gguf 格式文件）放进 models 文件夹内。

第二步：安装必备运行插件

打开终端 (Terminal) 或 命令提示符 (cmd)。依次复制并回车执行以下命令：

1. 升级 pip 工具 
python -m pip install --upgrade pip -i https://pypi.tuna.tsinghua.edu.cn/simple
2. 安装网页框架与文档处理库 
pip install gradio python-docx python-pptx -i https://pypi.tuna.tsinghua.edu.cn/simple
3. 安装高性能 AI 推理引擎 (Windows 推荐使用下方 AVX2 版本命令) 
pip install llama-cpp-python --extra-index-url https://jllllll.github.io/llama-cpp-python-cuBLAS-wheels/AVX2/cpu --only-binary=:all: --no-cache-dir

第三步：保存核心代码

在 OfflineTranslator 文件夹内，新建一个文本 file，重命名为 main.py。将管理员发放的 系统源代码 完整粘贴进去并保存。

第四步：创建“一键启动”脚本 (支持后台运行)

为了方便日后使用，请在 main.py 同级目录下新建对应的启动脚本。我们为您提供了两种模式：【全局绝对路径】(支持发送到桌面快捷方式/定时任务) 和 【当前相对路径】(适合直接在终端中运行)。

🟦 Windows 系统 (.bat 脚本)

[推荐] 模式 A：定义绝对路径 (随地双击 / 桌面快捷方式均可运行) 
@echo off
:: 🔥 强制 CMD 窗口使用全球通用 UTF-8 编码，彻底消灭所有中文和 Emoji 乱码！
chcp 65001 > nul

:: 🚀 设置命令行窗口的专属标题
title 局域网离线 AI 翻译服务器 - 纯本地运行

:: 自动获取当前bat所在的绝对路径，确保从桌面快捷方式双击也能正确运行
cd /d "%~dp0"

echo ==============================================
echo 🚀 正在启动局域网 AI 翻译服务器，请勿关闭此窗口...
echo ==============================================
echo.

python main.py

pause
模式 B：不定义路径 (直接在当前终端目录执行) 
@echo off
:: 🔥 强制 CMD 窗口使用全球通用 UTF-8 编码，彻底消灭所有中文和 Emoji 乱码！
chcp 65001 > nul

:: 🚀 设置命令行窗口的专属标题
title 局域网离线 AI 翻译服务器 - 纯本地运行

echo ==============================================
echo 🚀 正在当前目录启动局域网 AI 翻译服务器，请勿关闭此窗口...
echo ==============================================
echo.

python main.py

pause

🍏 Linux / macOS 系统 (.sh 脚本)

使用 nohup 后台运行，关闭 SSH/终端窗口后服务器依旧保持运行，日志将保存在 server_log.txt 中。
⚠️ 脚本创建后，需执行 chmod +x 启动脚本.sh 赋予运行权限。

[推荐] 模式 A：定义绝对路径 (支持任意位置调用 / Crontab 定时任务) 
#!/bin/bash
# 🔥 设置终端字符集，确保中文字符与 Emoji 不乱码
export LANG=zh_CN.UTF-8
export LC_ALL=zh_CN.UTF-8

# 🚀 设置终端窗口的专属标题
echo -ne "\033]0;局域网离线 AI 翻译服务器 - 纯本地运行\007"

# 自动解析并切换到本脚本所在的绝对路径
DIR="$( cd "$( dirname "${BASH_SOURCE[0]}" )" && pwd )"
cd "$DIR"

echo "=============================================="
echo "🚀 正在后台启动局域网 AI 翻译服务器..."
echo "=============================================="
echo ""

nohup python3 main.py > server_log.txt 2>&1 &

echo "✅ 启动成功！进程 PID: $!"
echo "📄 运行日志正实时输出至: $DIR/server_log.txt"
模式 B：不定义路径 (基于当前终端所在目录运行) 
#!/bin/bash
# 🔥 设置终端字符集，确保中文字符与 Emoji 不乱码
export LANG=zh_CN.UTF-8
export LC_ALL=zh_CN.UTF-8

# 🚀 设置终端窗口的专属标题
echo -ne "\033]0;局域网离线 AI 翻译服务器 - 纯本地运行\007"

echo "=============================================="
echo "🚀 正在当前目录后台启动局域网 AI 翻译服务器..."
echo "=============================================="
echo ""

nohup python3 main.py > server_log.txt 2>&1 &

echo "✅ 启动成功！进程 PID: $!"
echo "📄 运行日志正实时输出至: server_log.txt"

第五步：获取局域网地址并分享

双击或执行上述脚本启动服务器后。打开新的终端窗口，输入以下命令获取你本机的局域网 IP：

查询本机 IP 地址 (Windows: ipconfig / Linux&Mac: ifconfig) 
ipconfig

找到内网的 IPv4 地址（例如：192.168.1.100）。局域网内的设备只要在浏览器输入以下网址即可访问：

http://你的IP地址:7860
🛡️ 防火墙终极提醒： 如果同事输入网址打不开，说明是被防火墙拦截了。Windows 请在安全中心将 python.exe 放行；Linux 请执行 ufw allow 7860 开放端口。
