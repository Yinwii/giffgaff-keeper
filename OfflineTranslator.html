🚀 局域网专属 AI 翻译服务器
(全平台离线部署完整教程)

⚠️ 环境准备： 请确保电脑已安装 Python 3.11 (推荐) 或 3.12。请避开 Python 3.13（目前 AI 推理库尚未全面适配）。安装时请务必勾选 Add Python to PATH，并建议以管理员身份运行命令行（CMD）以规避沙箱权限受限问题。

第一步：建立项目文件夹与模型

1. 新建一个文件夹，命名为 OfflineTranslator，进入该文件夹。

2. 在里面再新建一个名为 models 的文件夹。

3. 将你下载好的 AI 模型文件（如 .gguf 格式文件）放进 models 文件夹内。

第二步：安装必备运行插件

打开命令提示符 (cmd)。由于不同网络环境下国内镜像站点的连通性存在差异，特为您提供两套镜像源安装方式。若清华源出现 403 拦截或报错，请直接使用阿里云镜像源：

1. 升级 pip 工具 (方案 A：阿里云源 - 推荐) 
python -m pip install --upgrade pip -i https://mirrors.aliyun.com/pypi/simple
1. 升级 pip 工具 (方案 B：清华源) 
python -m pip install --upgrade pip -i https://pypi.tuna.tsinghua.edu.cn/simple
2. 安装网页框架与文档处理库 (方案 A：阿里云源 - 推荐，规避 403 封锁) 
pip install gradio python-docx python-pptx -i https://mirrors.aliyun.com/pypi/simple
2. 安装网页框架与文档处理库 (方案 B：清华源) 
pip install gradio python-docx python-pptx -i https://pypi.tuna.tsinghua.edu.cn/simple
3. 安装高性能 AI 推理引擎 (在线极速版，使用阿里云加速) 
pip install llama-cpp-python -i https://mirrors.aliyun.com/pypi/simple --extra-index-url https://jllllll.github.io/llama-cpp-python-cuBLAS-wheels/AVX2/cpu --only-binary=:all: --no-cache-dir
💡 【强力推荐】离线浏览器下载安装法 (彻底解决 403 阻断与 GitHub 下载超时)：
如果在线安装时出现连接超时、找不到版本或握手失败等报错，说明终端网络访问受阻，请直接通过浏览器手动下载：
  1. 打开您的浏览器，访问预编译组件列表页：
    https://jllllll.github.io/llama-cpp-python-cuBLAS-wheels/AVX2/cpu
  2. 在文件列表中，根据您当前电脑安装的 Python 版本 下载对应的文件（认准 win_amd64 后缀）：

    • 如果您安装的是 Python 3.12：下载文件名包含 cp312 的文件，例如：llama_cpp_python-0.3.2-cp312-cp312-win_amd64.whl

    切换到系统下载文件夹 (Downloads)

    执行本地依赖安装 
    pip install llama_cpp_python-0.2.26+cpuavx2-cp311-cp311-win_amd64.whl -i https://mirrors.aliyun.com/pypi/simple

第三步：保存核心代码

在 OfflineTranslator 文件夹内，新建一个文本文件，重命名为 main.py。将管理员发放的 系统源代码 完整粘贴进去并保存。

第四步：创建“一键启动”脚本 (支持后台运行)

为了方便日后使用，请在 main.py 同级目录下新建对应的启动脚本。我们为您提供了两种模式：【全局绝对路径】(支持发送到桌面快捷方式/定时任务) 和 【当前相对路径】(适合直接在终端中运行)。

[推荐] 模式 A：定义绝对路径 (随地双击 / 桌面快捷方式均可运行) 
@echo off

chcp 65001 > nul

🍏 Linux / macOS 系统 (.sh 脚本)

使用 nohup 后台运行，关闭 SSH/终端窗口后服务器依旧保持运行，日志将保存在 server_log.txt 中。
⚠️ 脚本创建后，需执行 chmod +x 启动脚本.sh 赋予运行权限。

[推荐] 模式 A：定义绝对路径 (支持任意位置调用 / Crontab 定时任务) 
#!/bin/bash
# 🔥 设置终端字符集，确保中文字符与 Emoji 不乱码
export LANG=zh_CN.UTF-8
export LC_ALL=zh_CN.UTF-8

# 🚀 设置终端窗口的专属标题
echo -ne "\033]0;局域网离线 AI 翻译服务器 - 纯本地运行\007"

# 自动解析并切换到本脚本所在的绝对路径
DIR="$( cd "$( dirname "${BASH_SOURCE[0]}" )" && pwd )"
cd "$DIR"

echo "=============================================="
echo "🚀 正在后台启动局域网 AI 翻译服务器..."
echo "=============================================="
echo ""

nohup python3 main.py > server_log.txt 2>&1 &

echo "✅ 启动成功！进程 PID: $!"
echo "📄 运行日志正实时输出至: $DIR/server_log.txt"
模式 B：不定义路径 (基于当前终端所在目录运行)

echo "✅ 启动成功！进程 PID: $!"
echo "📄 运行日志正实时输出至: server_log.txt"

第五步：获取局域网地址并分享

双击或执行上述脚本启动服务器后。打开新的终端窗口，输入以下命令获取你本机的局域网 IP：

查询本机 IP 地址 (Windows: ipconfig / Linux&Mac: ifconfig) 
ipconfig

找到内网的 IPv4 地址（例如：192.168.1.100）。局域网内的设备只要在浏览器输入以下网址即可访问：

http://你的IP地址:7860
🛡️ 防火墙终极提醒： 如果同事输入网址打不开，说明是被防火墙拦截了。Windows 请在安全中心将 python.exe 放行；Linux 请执行 ufw allow 7860 开放端口。

💡 进阶：如何开启 GPU (显卡) 硬件加速（可选）

如果您的设备配有独立显卡（如 NVIDIA 显卡或 Apple M 系列芯片），可以按照以下步骤配置以启用显卡加速，从而显著提升翻译计算速度、减轻 CPU 负担。

1. 确认本地 CUDA 环境 (仅 Windows / Linux NVIDIA 用户)

在配置显卡运行前，请先打开终端（cmd）运行以下命令，确认系统已正确识别您的 NVIDIA 显卡与驱动版本：

查询显卡与 CUDA 支持版本 
nvidia-smi

若正常输出显卡状态表格，请关注右上角的 CUDA Version（或 CUDA UMD Version），根据该主版本号安装对应的显卡运行库。

2. 替换安装显卡版高性能 AI 推理引擎

在终端运行相应命令卸载旧版 CPU 依赖，并换装支持您硬件的显卡依赖库：

Windows + NVIDIA 显卡 (以 CUDA 12.1 为例) 
pip uninstall llama-cpp-python -y
pip install llama-cpp-python --extra-index-url https://jllllll.github.io/llama-cpp-python-cuBLAS-wheels/AVX2/cu121 --only-binary=:all: --no-cache-dir
macOS 系统 (Apple M系列芯片 Metal 原生加速) 
pip uninstall llama-cpp-python -y
CMAKE_ARGS="-GGuid=Xcode -DLLAMA_METAL=on" pip install llama-cpp-python --no-cache-dir --force-reinstall --no-binary :all:
Linux + NVIDIA 显卡 (CUDA 本地编译) 
pip uninstall llama-cpp-python -y
CMAKE_ARGS="-DLLAMA_CUDA=on" pip install llama-cpp-python --verbose --no-cache-dir --force-reinstall --no-binary :all:

3. 代码支持配置说明

在最新的 main.py 核心代码中，已预先配置了 n_gpu_layers=-1。系统在检测到显卡运行环境后，会自动将模型的计算图层全部卸载至 GPU 显存中运行。
