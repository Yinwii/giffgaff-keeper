Nginx Proxy Manager 根域名跳转配置指南

目标： 用户访问根域名时，自动跳转打开后端指定的某个文件路径。

第一步：基础详情设置 (Details)

在 Details 面板中，正常填写你的域名和后端 IP/端口。

⚠️ 严重易错点：
在 Forward Hostname / IP 栏目中，只能填写纯 IP 地址或纯域名（例如 152.53.86.5），绝对不能包含任何路径。

第二步：清理无用配置 (Custom Locations)

确保 Custom Locations 面板是空的。不要在这个面板里配置路径映射，否则会导致循环重定向或 502 错误。

第三步：生成并添加高级跳转代码 (Advanced)

在 Advanced 面板的 Custom Nginx Configuration 输入框中，粘贴以下生成的代码（点击右上角按钮一键复制）：

location = / {
    return 301 $scheme://$host/htools/bookmarktool.html;
}
关于 Trust Upstream Forwarded Proto Headers：
保持该选项为 关闭 (灰色) 状态即可。除非你的 NPM 前面还有一层负载均衡器（如 Cloudflare 代理），否则不需要开启此选项。
