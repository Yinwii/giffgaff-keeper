🤖 2. AI Agent 选型对决与部署规划（Hermes Agent vs OpenClaw）

决策结论：选择【Hermes Agent】，并落户在【Netcup-2oVPS (2C2G 60GB)】！
结合“方便维护管理、占用资源极少、功能恰到好处”的要求，Hermes 压倒性优于臃肿的 OpenClaw；确认 2oVPS 拥有 2G 内存与 60G 硬盘后，它更是承接个人 AI 智能体的天选之机。
为什么坚决选 Hermes 而非 OpenClaw？
选型胜出
  • 内存胃口天差地别：
    • OpenClaw：基于 Node.js 22，空闲吃 600M~900M，执行任务或压缩上下文时动辄飙升至 1.5GB ~ 3GB+，极其容易把 VPS 榨干；
    • Hermes Agent：基于轻量 Python + SQLite，守护进程仅占 ~250MB，Telegram 网关常驻仅 600MB ~ 900MB，运行平稳不漏内存。
  • 维护心智成本极低：
    • OpenClaw 架构庞大（多渠道网关/消息总线），插件市场频繁更新断配；
    • Hermes 采用单文件 config.yaml，具备自学技能机制（Curator），无需配置繁琐插件，对个人 24 小时挂机助理最友好。
为什么 Hermes 必须落在 Netcup-2oVPS？
架构深意
  • 保护 BW25 的邮箱 IP（最大安全红线）：
    • BW25 运行着邮件服务器（对 IP 纯净度极度敏感）。AI Agent 频繁上网搜索、爬取链接，如果放在 BW25，极易导致邮件 IP 被拉黑（RBL）；放在 2oVPS 可彻底实现网络与 IP 隔离。
  • 与“个人私有工作台”天然协同：
    • 2oVPS 运行着笔记（Inkstone/Memos）和私有网盘（Filebrowser）。Hermes 作为个人助理，通过 Docker 目录只读挂载，未来能直接阅读个人笔记做本地知识库检索（RAG），体验浑然一体。
  • 2C 2G 60GB 资源绰绰有余：
    • 2oVPS 现有服务仅吃 300MB，净余 1.4GB 内存；给 Hermes 划定 1.2G 硬限制后，仍有充裕安全垫。
🛠️ Netcup-2oVPS 上的 Hermes Agent 生产部署模板 (`docker-compose.yml`)

在 /root/data/docker/hermes 目录下创建配置，严格限制内存上限为 1200M，挂载专属数据卷，杜绝容器逃逸与资源挤占： 

services:
  hermes:
    image: nousresearch/hermes-agent:latest
    container_name: hermes-agent
    restart: unless-stopped
    volumes:
      # 持久化存储 Agent 会话记忆、自学技能与 SQLite 数据库
      - /root/data/docker/hermes/data:/opt/data
      # (可选) 将个人笔记只读挂载给 Agent，供其学习个人知识库 (安全防篡改)
      # - /root/data/docker/notes:/opt/knowledge_base:ro
    environment:
      - TZ=Asia/Shanghai
      # 配置 Telegram Bot Token 与 LLM API 密钥 (建议写入 .env 文件)
      - TELEGRAM_BOT_TOKEN=your_bot_token_here
      - OPENROUTER_API_KEY=your_openrouter_key_here
    deploy:
      resources:
        limits:
          cpus: '1.5'          # 最多调用 1.5 核
          memory: 1200M        # 内存硬上限 1.2G，为宿主机及笔记服务硬留 800MB 物理内存

⚡ 6. 桌面环境与高占用进程清理复盘 (SOP)

此前由于后台常驻的 Epiphany 浏览器及 WebKitWebProcess 死循环，导致双核机器 Load Average 飙升至 6.0+。标准清除流程：

# 1. 立即停止并禁用 xrdp 与 lightdm 桌面环境服务
sudo systemctl stop xrdp lightdm
sudo systemctl disable xrdp lightdm

# 2. 强杀残留的所有桌面与 WebKit 渲染进程
sudo pkill -9 -f 'WebKitWebProcess|epiphany|xfce|xfwm4|xrdp|lightdm|Xorg'

# 3. 切换默认系统启动级别为纯命令行模式（multi-user）
sudo systemctl set-default multi-user.target

# 4. 彻底卸载清理桌面组件包并清理废弃依赖包
sudo apt purge -y xrdp xorgxrdp lightdm 'xfce4*' 'xfwm4*' 'xserver-xorg*' epiphany-browser
sudo apt autoremove --purge -y && sudo apt clean

# 5. 1C1G 小鸡（如 Netcup 1o）快速开启 2G Swap 防爆内存
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile
sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
