OVH 自建顶级邮局实战指南

✅ 硬件与环境就绪检查：
  • CPU/内存： 4核 8GB (完美运行各类型邮局方案)
  • 内核优化： XanMod v3 + BBRv3 (加速附件传输，极致抗丢包)
  • 网络端口： 25 端口出站/入站双向开启 (建邮局的核心入场券)
  • IP 类型： OVH 原生 IPv4 + IPv6

1 核心准备：设置 PTR (反向解析)

这是邮局信誉度的基础。没有 PTR 记录，Gmail 等主流厂商会直接拒收邮件。

操作位置： 登录 OVH 控制面板 -> IP 管理 -> 选择对应的 IP 地址。
  • IPv4 PTR： 将 15.204.x.x 的 Reverse DNS 设置为 mail.yourdomain.com
  • IPv6 PTR： 将 2604:2dc0:202:300::2a47 同样设置为 mail.yourdomain.com

2 域名解析 (DNS) 配置

在你的域名服务商（如 Cloudflare）处添加以下记录。注意：必须关闭小黄云（改为灰色云朵 DNS Only）。

记录类型 主机记录 记录值 备注
A mail 15.204.x.x 指向你的 IPv4 地址
AAAA mail 2604:2dc0:202:300::2a47 指向你的 IPv6 地址
MX @ mail.yourdomain.com 优先级设为 10
TXT @ v=spf1 mx ~all SPF 记录：授权服务器发信
TXT _dmarc v=DMARC1; p=quarantine; adkim=r; aspf=r DMARC 记录：安全策略

3 方案选型：找到最适合你的邮局

方案名称 内存消耗 管理界面 适用场景
Mailcow 3.5GB+ 功能极其强大 全能、商业级、抗垃圾引擎顶级
Stalwart 500MB 现代、简洁 轻量、高性能 Rust 编写、支持 JMAP
Maddy 100MB 纯命令行 极致极简、资源占用极低
Postal 4GB+ 发信管理系统 发信引擎，适合验证码/推送业务

4 部署操作 (方案建议二选一)

方案 A：Mailcow (全能型，首选推荐)

# 部署命令
curl -sSL https://get.docker.com/ | sh
cd /opt
sudo git clone https://github.com/mailcow/mailcow-dockerized
cd mailcow-dockerized
sudo ./generate_config.sh # 输入 mail.yourdomain.com
sudo docker compose up -d

# 默认后台: https://mail.yourdomain.com
# 账号密码: admin / moohoo

方案 B：Stalwart (轻量现代化，Rust 驱动)

# 使用 Docker 极速部署
docker run -d --name stalwart \
  -p 25:25 -p 465:465 -p 587:587 -p 993:993 -p 8080:8080 \
  -v /opt/stalwart-mail:/opt/stalwart-mail \
  ghcr.io/stalwartlabs/mail-server:latest

# 查看自动生成的 admin 密码:
docker logs stalwart | grep "admin"
# 后台地址: http://服务器IP:8080

5 配置 DKIM 签名

部署好并进入后台创建好邮箱账号后，必须配置 DKIM 以大幅提高发信成功率：

Mailcow： Configuration -> Mail Setup -> Domains -> 填写 Selector 为 dkim -> 生成并复制公钥。

Stalwart： Settings -> Domains -> Signing Keys -> 创建 Selector 为 stalwart 的密钥。

DNS 设置： 在 Cloudflare 添加 TXT 记录，名称为 选择器._domainkey（例如 dkim._domainkey），内容为生成的以 v=DKIM1; 开头的整段字符串。

6 终极测试：邮件跑分

访问 Mail-Tester.com 发送测试信。凭借 XanMod BBR3 和 正确的双栈 PTR，您将极大概率获得 10/10 满分。

7 客户端配置：将邮箱添加至手机与 PC

在所有设备的手动配置界面，请统一使用以下参数：

通用连接参数：
• 用户名： 您的完整邮箱地址 (如 admin@yourdomain.com)
• 密码： 您在邮局后台设置的密码
• 收件服务器 (IMAP)： mail.yourdomain.com | 端口：993 | 加密：SSL/TLS
• 发件服务器 (SMTP)： mail.yourdomain.com | 端口：465 | 加密：SSL/TLS

📱 在 iPhone (iOS) / Android 上添加

  1. 进入设置 -> 邮件/帐号 -> 添加帐号 -> 其他。
  2. 选择 添加邮件帐号 (IMAP)。
  3. 输入账号信息，并在收件和发件服务器处均填入 mail.yourdomain.com。
  4. 确保发件服务器也填写了用户名和密码（即使系统标记为选填）。

💻 在 PC (Outlook / Thunderbird) 上添加

  1. 选择 手动设置 账户。
  2. 账户类型选择 IMAP。
  3. 按照上述参数填入端口 993 和 465，并勾选对应的 SSL/TLS 加密。
⚠️ 连接失败排查：
如果无法连接，请在 VPS 终端运行以下命令开放防火墙端口：
sudo ufw allow 993/tcp && sudo ufw allow 465/tcp && sudo ufw allow 587/tcp
