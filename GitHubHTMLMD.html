智能极速渲染

自动识别 GitHub 路径。HTML 文件直接渲染为网页；Markdown (.md) 自动套用 GitHub 官方排版样式，阅读体验拉满。

全网链接兼容

不仅仅是 GitHub！粘贴任意外部网站链接，系统会自动拆分前缀，利用安全沙盒模式极速内嵌加载，支持全网预览。

📚

强大历史管控

本地化存储浏览记录，支持置顶 📌、收藏 ⭐。支持卡片/列表视图切换，内置实时高亮搜索，并且支持一键下载源文件。

沉浸式阅读设计

告别刺眼的悬浮按钮！处于渲染状态时，鼠标滑动至默认的右上角区域，即可丝滑唤出退出预览按钮。若发生遮挡，右键点击该按钮即可自动切换至其他角落避让，绝不干扰阅读体验。

快速上手指引

1
在其它页面复制你想要查看的 GitHub 文件链接或任意网址。
2
点击顶部输入框右侧的 [粘贴] 按钮（系统会自动读取剪贴板并解析路径）。
3
点击 [一键渲染]，即可在此区域沉浸式浏览网页或文档内容！
